A deterministic Node program that writes one two-part micro-confession to `/output/entry.txt`: a `To:` line naming who it was meant for, then the unsent line itself, exactly as typed, with nothing after it. The confession is specific and honest, and the reason it stayed in drafts is felt in the words — never stated, never explained.

## Run it

```sh
node main.ts
```
